One panel that installs, updates and connects the whole suite.

Each extension below works entirely on its own. Together they talk to each other — the backpack
knows what the vendor sells, the diary remembers what the map says you did. The hub exists so you
do not have to find fifteen repositories, paste fifteen endpoints, and keep fifteen versions in
your head.



---

## 📦 Install

In SillyTavern, go to **Extensions → Install Extension** and paste the Hub's GitHub URL.

Open the **Tavern RPG Suite** drawer and the Hub will show you what is installed, what needs updating, and what is missing — without making you check everything manually.

The extension catalogue comes from `suite.json`, so new extensions can appear in the Hub without requiring a new Hub release. If GitHub cannot be reached, the Hub falls back to its bundled catalogue.

## 🔗 One Shared Connection

Most extensions can use their own AI endpoint, but configuring the same URL, key and model over and over is unnecessary.

The Hub provides **one shared AI profile** that extensions can use whenever their own settings are empty. You can see which extensions are using it and restore an extension to the shared profile with **Use Shared**.

Nothing is changed inside another extension's settings without your action. You can still give individual extensions their own models whenever you want.

### 🖥️ Local Models

Local backends are supported too, including **KoboldCpp, oobabooga, LM Studio, Ollama**, and other OpenAI-compatible servers running on your computer or LAN.

Local endpoints such as `localhost` and `127.0.0.1` are recognised automatically, with `/v1` added when needed and API keys treated as optional.

## 🔄 Updates

Each installed extension is checked against its repository and marked as:

* ✅ **Ready** — already up to date.
* 🔄 **Update** — a newer version is available.
* 📦 **Zip** — installed manually without a Git repository, so it can be installed but not updated in place.

Set **Updates** to **Automatic** to apply available updates automatically, or use **Ask me** to approve them yourself.

**Install for all users** is available for multi-user SillyTavern setups.

---

## 📝 Notes

The Hub checks SillyTavern's actual extension settings to confirm what is installed, rather than relying only on SillyTavern's extension list.

The Hub only connects externally to **GitHub**, for the extension catalogue and version checks.
